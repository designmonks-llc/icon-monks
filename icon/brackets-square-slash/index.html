Brackets Square Slash icon

The brackets square slash icon is a free development icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the brackets square slash icon

It is the crossed-out version of the brackets square icon, for when it is off, blocked or unavailable, so it keeps the exact outline of the brackets square icon. Use it to stand for brackets square, disabled and off. The regular weight is a single path made of 5 shapes.

Pairs well with the matrix, basket code and bell code icons, which share the “brackets” theme. Use the same weight for all of them so they read as one set.

When to use the brackets square slash icon

It belongs to the development set, made for code, terminals, version control and developer tools. People find it by searching for “brackets square”, “disabled”, “off”, “brackets” and “code”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the brackets square slash icon

Is the brackets square slash icon free for commercial use?

Yes. The brackets square slash icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the brackets square slash icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the brackets square slash and brackets square icons?

The brackets square slash icon is the crossed-out version of the brackets square icon, for when it is off, blocked or unavailable. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
