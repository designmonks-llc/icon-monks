File Doc icon

The file doc icon is a free files icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the file doc icon

It is a doc variant of the file icon, so it keeps the exact outline of the file icon. Use it to stand for doc, word and document. The regular weight is a single path made of 7 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the crossword, text whole word and blood type icons, which share the “word” theme. Use the same weight for all of them so they read as one set.

When to use the file doc icon

It belongs to the files set, made for documents, folders, file types and storage. People find it by searching for “doc”, “word”, “document”, “file type” and “word document”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the file doc icon

Is the file doc icon free for commercial use?

Yes. The file doc icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the file doc icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the file doc and file icons?

The file doc icon is a doc variant of the file icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
