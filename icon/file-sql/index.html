File Sql icon

The file sql icon is a free files icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the file sql icon

It is a sql variant of the file icon, so it keeps the exact outline of the file icon. Use it to stand for sql, database and query. The regular weight is a single path made of 6 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the database code and cloud database icons, which share the “sql” theme. Use the same weight for all of them so they read as one set.

When to use the file sql icon

It belongs to the files set, made for documents, folders, file types and storage. People find it by searching for “sql”, “database”, “query”, “file type” and “query file”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the file sql icon

Is the file sql icon free for commercial use?

Yes. The file sql icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the file sql icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the file sql and file icons?

The file sql icon is a sql variant of the file icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
