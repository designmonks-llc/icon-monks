Transition Top icon

The transition top icon is a free design icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the transition top icon

Use it to stand for transition, slide and animation. The regular weight is a single path made of 2 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the ease in, status change and hand swipe left icons, which share the “transition” theme. Use the same weight for all of them so they read as one set.

When to use the transition top icon

It belongs to the design set, made for design tools, editors and creative apps. People find it by searching for “transition”, “slide”, “animation” and “top”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the transition top icon

Is the transition top icon free for commercial use?

Yes. The transition top icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the transition top icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the transition top icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
