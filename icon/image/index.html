Image icon

The image icon is a free media icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the image icon

Use it to stand for photo, picture and gallery. The regular weight is a single path made of 5 shapes, and the duotone weight adds a 20% tint behind the outline. It comes with ten or more variants for states and actions: image actual size, image arrow down, image arrow up, image bitcoin, image broken, image check, image code, image compare, image composition and image currency dollar.

Pairs well with the camera, slideshow and crop landscape icons, which share the “photo” theme. Use the same weight for all of them so they read as one set.

When to use the image icon

It belongs to the media set, made for audio, video, playback and streaming controls. People find it by searching for “photo”, “picture”, “gallery” and “landscape”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the image icon

Is the image icon free for commercial use?

Yes. The image icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the image icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Are there variants of the image icon?

Yes. The image icon has ten or more variants, including image actual size, image arrow down, image arrow up and image bitcoin. Each one keeps the same base shape and comes in all six weights.
