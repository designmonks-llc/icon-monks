Newspaper icon

A free newspaper icon from the Files set, useful for news, article, press, blog. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the newspaper icon in your code

React

import { Newspaper } from '@icon-monks/react';

<Newspaper size={24} />

Vue

<script setup>
import { Newspaper } from '@icon-monks/vue';
</script>

<Newspaper :size="24" />

Web component

<icon-monks name="newspaper" size="24"></icon-monks>

Icon font

<i class="im im-newspaper"></i>

Flutter

Icon(IconMonks.newspaper)

SwiftUI

Image(iconMonks: .newspaper)

Compose

Icon(IconMonks.Regular.Newspaper, contentDescription = null)
