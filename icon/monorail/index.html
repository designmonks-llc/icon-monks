Monorail icon

A free monorail icon from the Transport set, useful for train, elevated rail, transit. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the monorail icon in your code

React

import { Monorail } from '@icon-monks/react';

<Monorail size={24} />

Vue

<script setup>
import { Monorail } from '@icon-monks/vue';
</script>

<Monorail :size="24" />

Web component

<icon-monks name="monorail" size="24"></icon-monks>

Icon font

<i class="im im-monorail"></i>

Flutter

SwiftUI

Compose
