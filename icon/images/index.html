Images icon

A free images icon from the Media set, useful for gallery, photos, album, pictures. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the images icon in your code

React

import { Images } from '@icon-monks/react';

<Images size={24} />

Vue

<script setup>
import { Images } from '@icon-monks/vue';
</script>

<Images :size="24" />

Web component

<icon-monks name="images" size="24"></icon-monks>

Icon font

<i class="im im-images"></i>

Flutter

Icon(IconMonks.images)

SwiftUI

Image(iconMonks: .images)

Compose

Icon(IconMonks.Regular.Images, contentDescription = null)
