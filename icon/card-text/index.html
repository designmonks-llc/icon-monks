Card Text icon

A free card text icon from the Interface set, useful for card, content, text, panel. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the card text icon in your code

React

import { CardText } from '@icon-monks/react';

<CardText size={24} />

Vue

<script setup>
import { CardText } from '@icon-monks/vue';
</script>

<CardText :size="24" />

Web component

<icon-monks name="card-text" size="24"></icon-monks>

Icon font

<i class="im im-card-text"></i>

Flutter

Icon(IconMonks.cardText)

SwiftUI

Image(iconMonks: .cardText)

Compose

Icon(IconMonks.Regular.CardText, contentDescription = null)
