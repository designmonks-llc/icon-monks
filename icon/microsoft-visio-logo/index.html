Microsoft Visio Logo icon

The microsoft visio logo icon is a free brands icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the microsoft visio logo icon

Use it to stand for microsoft visio, visio and microsoft. The regular weight is a single path made of 5 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the flowchart, line elbow and graph icons, which share the “diagram” theme. Use the same weight for all of them so they read as one set.

When to use the microsoft visio logo icon

It belongs to the brands set, made for sign-in buttons, footers, share menus and integrations. People find it by searching for “microsoft visio”, “visio”, “microsoft”, “diagram”, “flowchart” and “office”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the microsoft visio logo icon

Is the microsoft visio logo icon free for commercial use?

Yes. The microsoft visio logo icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the microsoft visio logo icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the microsoft visio logo icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
