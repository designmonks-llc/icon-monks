Screen Share icon

A free screen share icon from the Devices set, useful for screen share, cast, present, monitor. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the screen share icon in your code

React

import { ScreenShare } from '@icon-monks/react';

<ScreenShare size={24} />

Vue

<script setup>
import { ScreenShare } from '@icon-monks/vue';
</script>

<ScreenShare :size="24" />

Web component

<icon-monks name="screen-share" size="24"></icon-monks>

Icon font

<i class="im im-screen-share"></i>

Flutter

Icon(IconMonks.screenShare)

SwiftUI

Image(iconMonks: .screenShare)

Compose

Icon(IconMonks.Regular.ScreenShare, contentDescription = null)
