Thumbs Up icon

A free thumbs up icon from the Interface set, useful for like, approve, agree, good. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

React

Vue

import { ThumbsUp } from '@icon-monks/vue';
</script>

Web component

Icon font

Flutter

SwiftUI

Compose
