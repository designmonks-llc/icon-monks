Line Height icon

A free line height icon from the Editor set, useful for line height, spacing, leading, typography. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the line height icon in your code

React

import { LineHeight } from '@icon-monks/react';

<LineHeight size={24} />

Vue

<script setup>
import { LineHeight } from '@icon-monks/vue';
</script>

<LineHeight :size="24" />

Web component

<icon-monks name="line-height" size="24"></icon-monks>

Icon font

<i class="im im-line-height"></i>

Flutter

Icon(IconMonks.lineHeight)

SwiftUI

Image(iconMonks: .lineHeight)

Compose

Icon(IconMonks.Regular.LineHeight, contentDescription = null)
