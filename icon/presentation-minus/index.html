Presentation Minus icon

The presentation minus icon is a free business icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the presentation minus icon

It is the presentation icon with a minus badge, for removing, so it keeps the exact outline of the presentation icon. Use it to stand for presentation, remove and board. The regular weight is a single path made of 3 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the building office x, presenter and projector screen icons, which share the “presentation” theme. Use the same weight for all of them so they read as one set.

When to use the presentation minus icon

It belongs to the business set, made for finance, offices and productivity. People find it by searching for “presentation”, “remove”, “board” and “minus”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the presentation minus icon

Is the presentation minus icon free for commercial use?

Yes. The presentation minus icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the presentation minus icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the presentation minus and presentation icons?

The presentation minus icon is the presentation icon with a minus badge, for removing. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
