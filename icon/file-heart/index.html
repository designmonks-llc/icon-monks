File Heart icon

A free file heart icon from the Files set, useful for document, favorite, love, file. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the file heart icon in your code

React

import { FileHeart } from '@icon-monks/react';

<FileHeart size={24} />

Vue

<script setup>
import { FileHeart } from '@icon-monks/vue';
</script>

<FileHeart :size="24" />

Web component

<icon-monks name="file-heart" size="24"></icon-monks>

Icon font

<i class="im im-file-heart"></i>

Flutter

Icon(IconMonks.fileHeart)

SwiftUI

Image(iconMonks: .fileHeart)

Compose

Icon(IconMonks.Regular.FileHeart, contentDescription = null)
