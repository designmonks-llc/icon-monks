Hexagon icon

The hexagon icon is a free interface icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the hexagon icon

Use it to stand for shape, polygon and honeycomb. The regular weight is a single path made of 2 shapes, and the duotone weight adds a 20% tint behind the outline. It comes with 3 variants for states and actions: hexagon minus, hexagon plus and hexagon slash.

Pairs well with the octagon, diamond and triangle icons, which share the “shape” theme. Use the same weight for all of them so they read as one set.

When to use the hexagon icon

It belongs to the interface set, made for buttons, menus, toolbars and app navigation. People find it by searching for “shape”, “polygon”, “honeycomb” and “geometry”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the hexagon icon

Is the hexagon icon free for commercial use?

Yes. The hexagon icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the hexagon icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Are there variants of the hexagon icon?

Yes. The hexagon icon has 3 variants, including hexagon minus, hexagon plus and hexagon slash. Each one keeps the same base shape and comes in all six weights.
