Favicon icon

A free favicon icon from the Development set, useful for site icon, browser. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the favicon icon in your code

React

import { Favicon } from '@icon-monks/react';

<Favicon size={24} />

Vue

<script setup>
import { Favicon } from '@icon-monks/vue';
</script>

<Favicon :size="24" />

Web component

<icon-monks name="favicon" size="24"></icon-monks>

Icon font

<i class="im im-favicon"></i>

Flutter

Icon(IconMonks.favicon)

SwiftUI

Image(iconMonks: .favicon)

Compose

Icon(IconMonks.Regular.Favicon, contentDescription = null)
