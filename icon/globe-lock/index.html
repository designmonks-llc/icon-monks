Globe Lock icon

The globe lock icon is a free security icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the globe lock icon

It is the globe icon with a lock badge, for private or protected items, so it keeps the exact outline of the globe icon. Use it to stand for secure web, vpn and private network. The regular weight is a single path made of 8 shapes, and the duotone weight adds a 20% tint behind the outline.

When to use the globe lock icon

It belongs to the security set, made for locks, privacy, authentication and safety. People find it by searching for “secure web”, “vpn”, “private network”, “globe”, “lock” and “https”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the globe lock icon

Is the globe lock icon free for commercial use?

Yes. The globe lock icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the globe lock icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the globe lock and globe icons?

The globe lock icon is the globe icon with a lock badge, for private or protected items. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
