Text Columns icon

A free text columns icon from the Editor set, useful for columns, multi-column text, layout, newspaper layout. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text columns icon in your code

React

import { TextColumns } from '@icon-monks/react';

<TextColumns size={24} />

Vue

<script setup>
import { TextColumns } from '@icon-monks/vue';
</script>

<TextColumns :size="24" />

Web component

<icon-monks name="text-columns" size="24"></icon-monks>

Icon font

<i class="im im-text-columns"></i>

Flutter

Icon(IconMonks.textColumns)

SwiftUI

Image(iconMonks: .textColumns)

Compose

Icon(IconMonks.Regular.TextColumns, contentDescription = null)
