File Vector icon

A free file vector icon from the Files set, useful for vector file, bezier, graphic, design. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the file vector icon in your code

React

import { FileVector } from '@icon-monks/react';

<FileVector size={24} />

Vue

<script setup>
import { FileVector } from '@icon-monks/vue';
</script>

<FileVector :size="24" />

Web component

<icon-monks name="file-vector" size="24"></icon-monks>

Icon font

<i class="im im-file-vector"></i>

Flutter

Icon(IconMonks.fileVector)

SwiftUI

Image(iconMonks: .fileVector)

Compose

Icon(IconMonks.Regular.FileVector, contentDescription = null)
