Text Kerning icon

A free text kerning icon from the Editor set, useful for kerning, letter spacing, typography, text. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text kerning icon in your code

React

import { TextKerning } from '@icon-monks/react';

<TextKerning size={24} />

Vue

<script setup>
import { TextKerning } from '@icon-monks/vue';
</script>

<TextKerning :size="24" />

Web component

<icon-monks name="text-kerning" size="24"></icon-monks>

Icon font

<i class="im im-text-kerning"></i>

Flutter

Icon(IconMonks.textKerning)

SwiftUI

Image(iconMonks: .textKerning)

Compose

Icon(IconMonks.Regular.TextKerning, contentDescription = null)
