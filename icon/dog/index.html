Dog icon

The dog icon is a free animals icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the dog icon

Use it to stand for puppy, pet and canine. The regular weight is a single path made of 7 shapes, and the duotone weight adds a 20% tint behind the outline. It comes with 1 variant for states and actions: dog bowl.

Pairs well with the cat, bat and bear icons, which share the “pet” theme. Use the same weight for all of them so they read as one set.

When to use the dog icon

It belongs to the animals set, made for pets, wildlife and playful interfaces. People find it by searching for “puppy”, “pet”, “canine” and “animal”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the dog icon

Is the dog icon free for commercial use?

Yes. The dog icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the dog icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Are there variants of the dog icon?

Yes. The dog icon has 1 variant, including dog bowl. Each one keeps the same base shape and comes in all six weights.
