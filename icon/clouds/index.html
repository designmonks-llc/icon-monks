Clouds icon

A free clouds icon from the Weather set, useful for cloudy, overcast, weather. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the clouds icon in your code

React

import { Clouds } from '@icon-monks/react';

<Clouds size={24} />

Vue

<script setup>
import { Clouds } from '@icon-monks/vue';
</script>

<Clouds :size="24" />

Web component

<icon-monks name="clouds" size="24"></icon-monks>

Icon font

<i class="im im-clouds"></i>

Flutter

Icon(IconMonks.clouds)

SwiftUI

Image(iconMonks: .clouds)

Compose

Icon(IconMonks.Regular.Clouds, contentDescription = null)
