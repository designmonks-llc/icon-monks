Onigiri icon

A free onigiri icon from the Food set, useful for rice ball, japanese food, snack. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the onigiri icon in your code

React

import { Onigiri } from '@icon-monks/react';

<Onigiri size={24} />

Vue

<script setup>
import { Onigiri } from '@icon-monks/vue';
</script>

<Onigiri :size="24" />

Web component

<icon-monks name="onigiri" size="24"></icon-monks>

Icon font

<i class="im im-onigiri"></i>

Flutter

Icon(IconMonks.onigiri)

SwiftUI

Image(iconMonks: .onigiri)

Compose
