Phone Slash icon

A free phone slash icon from the Communication set, useful for no calls, phone off, muted calls, phone disabled. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the phone slash icon in your code

React

import { PhoneSlash } from '@icon-monks/react';

<PhoneSlash size={24} />

Vue

<script setup>
import { PhoneSlash } from '@icon-monks/vue';
</script>

<PhoneSlash :size="24" />

Web component

<icon-monks name="phone-slash" size="24"></icon-monks>

Icon font

<i class="im im-phone-slash"></i>

Flutter

Icon(IconMonks.phoneSlash)

SwiftUI

Image(iconMonks: .phoneSlash)

Compose

Icon(IconMonks.Regular.PhoneSlash, contentDescription = null)
