Briefcase icon

A free briefcase icon from the Business set, useful for work, business, job, office. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the briefcase icon in your code

React

import { Briefcase } from '@icon-monks/react';

<Briefcase size={24} />

Vue

<script setup>
import { Briefcase } from '@icon-monks/vue';
</script>

<Briefcase :size="24" />

Web component

<icon-monks name="briefcase" size="24"></icon-monks>

Icon font

<i class="im im-briefcase"></i>

Flutter

Icon(IconMonks.briefcase)

SwiftUI

Image(iconMonks: .briefcase)

Compose

Icon(IconMonks.Regular.Briefcase, contentDescription = null)
