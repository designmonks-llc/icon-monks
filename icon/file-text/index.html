File Text icon

A free file text icon from the Files set, useful for document, text, article, notes. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the file text icon in your code

React

import { FileText } from '@icon-monks/react';

<FileText size={24} />

Vue

<script setup>
import { FileText } from '@icon-monks/vue';
</script>

<FileText :size="24" />

Web component

<icon-monks name="file-text" size="24"></icon-monks>

Icon font

<i class="im im-file-text"></i>

Flutter

Icon(IconMonks.fileText)

SwiftUI

Image(iconMonks: .fileText)

Compose

Icon(IconMonks.Regular.FileText, contentDescription = null)
