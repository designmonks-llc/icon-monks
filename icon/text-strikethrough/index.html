Text Strikethrough icon

A free text strikethrough icon from the Editor set, useful for strikethrough, strike, format, delete. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text strikethrough icon in your code

React

import { TextStrikethrough } from '@icon-monks/react';

<TextStrikethrough size={24} />

Vue

<script setup>
import { TextStrikethrough } from '@icon-monks/vue';
</script>

<TextStrikethrough :size="24" />

Web component

<icon-monks name="text-strikethrough" size="24"></icon-monks>

Icon font

<i class="im im-text-strikethrough"></i>

Flutter

Icon(IconMonks.textStrikethrough)

SwiftUI

Image(iconMonks: .textStrikethrough)

Compose

Icon(IconMonks.Regular.TextStrikethrough, contentDescription = null)
