Chat Image icon

A free chat image icon from the Communication set, useful for chat, image, photo, message. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the chat image icon in your code

React

import { ChatImage } from '@icon-monks/react';

<ChatImage size={24} />

Vue

<script setup>
import { ChatImage } from '@icon-monks/vue';
</script>

<ChatImage :size="24" />

Web component

<icon-monks name="chat-image" size="24"></icon-monks>

Icon font

<i class="im im-chat-image"></i>

Flutter

Icon(IconMonks.chatImage)

SwiftUI

Image(iconMonks: .chatImage)

Compose

Icon(IconMonks.Regular.ChatImage, contentDescription = null)
