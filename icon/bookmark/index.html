Bookmark icon

A free bookmark icon from the Interface set, useful for save, favorite, read later. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the bookmark icon in your code

React

import { Bookmark } from '@icon-monks/react';

<Bookmark size={24} />

Vue

<script setup>
import { Bookmark } from '@icon-monks/vue';
</script>

<Bookmark :size="24" />

Web component

<icon-monks name="bookmark" size="24"></icon-monks>

Icon font

<i class="im im-bookmark"></i>

Flutter

Icon(IconMonks.bookmark)

SwiftUI

Image(iconMonks: .bookmark)

Compose

Icon(IconMonks.Regular.Bookmark, contentDescription = null)
