Table Pivot icon

The table pivot icon is a free charts icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the table pivot icon

It is a pivot variant of the table icon, so it keeps the exact outline of the table icon. Use it to stand for pivot table, crosstab and spreadsheet. The regular weight is a single path made of 6 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the chart scatter, clipboard data and a b test icons, which share the “data” theme. Use the same weight for all of them so they read as one set.

When to use the table pivot icon

It belongs to the charts set, made for dashboards, analytics and data visualization. People find it by searching for “pivot table”, “crosstab”, “spreadsheet” and “data”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the table pivot icon

Is the table pivot icon free for commercial use?

Yes. The table pivot icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the table pivot icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the table pivot and table icons?

The table pivot icon is a pivot variant of the table icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
