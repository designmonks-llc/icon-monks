Aspect Ratio icon

A free aspect ratio icon from the Design set, useful for ratio, aspect, dimensions, crop. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the aspect ratio icon in your code

React

import { AspectRatio } from '@icon-monks/react';

<AspectRatio size={24} />

Vue

<script setup>
import { AspectRatio } from '@icon-monks/vue';
</script>

Web component

<icon-monks name="aspect-ratio" size="24"></icon-monks>

Icon font

Flutter

SwiftUI

Image(iconMonks: .aspectRatio)

Compose
