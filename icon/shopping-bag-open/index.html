Shopping Bag Open icon

A free shopping bag open icon from the Commerce set, useful for open bag, shopping, purchase. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the shopping bag open icon in your code

React

import { ShoppingBagOpen } from '@icon-monks/react';

<ShoppingBagOpen size={24} />

Vue

<script setup>
import { ShoppingBagOpen } from '@icon-monks/vue';
</script>

<ShoppingBagOpen :size="24" />

Web component

<icon-monks name="shopping-bag-open" size="24"></icon-monks>

Icon font

Flutter

Icon(IconMonks.shoppingBagOpen)

SwiftUI

Image(iconMonks: .shoppingBagOpen)
