Layout Image Top icon

A free layout image top icon from the Editor set, useful for image above text, insert image, layout, content block. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the layout image top icon in your code

React

import { LayoutImageTop } from '@icon-monks/react';

<LayoutImageTop size={24} />

Vue

<script setup>
import { LayoutImageTop } from '@icon-monks/vue';
</script>

<LayoutImageTop :size="24" />

Web component

<icon-monks name="layout-image-top" size="24"></icon-monks>

Icon font

<i class="im im-layout-image-top"></i>

Flutter

Icon(IconMonks.layoutImageTop)

SwiftUI

Image(iconMonks: .layoutImageTop)

Compose

Icon(IconMonks.Regular.LayoutImageTop, contentDescription = null)
