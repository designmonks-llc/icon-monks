Picnic Table icon

The picnic table icon is a free maps icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

When to use the picnic table icon

It belongs to the maps set, made for locations, navigation and travel apps. People find it by searching for “picnic”, “table”, “park” and “outdoors”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the picnic table icon

Is the picnic table icon free for commercial use?

Yes. The picnic table icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the picnic table icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the picnic table icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
