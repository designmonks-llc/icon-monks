Dimensions icon

A free dimensions icon from the Design set, useful for measure, size, width. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the dimensions icon in your code

React

import { Dimensions } from '@icon-monks/react';

<Dimensions size={24} />

Vue

<script setup>
import { Dimensions } from '@icon-monks/vue';
</script>

<Dimensions :size="24" />

Web component

<icon-monks name="dimensions" size="24"></icon-monks>

Icon font

<i class="im im-dimensions"></i>

Flutter

Icon(IconMonks.dimensions)

SwiftUI

Image(iconMonks: .dimensions)

Compose

Icon(IconMonks.Regular.Dimensions, contentDescription = null)
