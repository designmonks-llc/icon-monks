Vignette icon

A free vignette icon from the Media set, useful for photo effect, edge, filter. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the vignette icon in your code

React

import { Vignette } from '@icon-monks/react';

<Vignette size={24} />

Vue

import { Vignette } from '@icon-monks/vue';
</script>

Web component

Icon font

SwiftUI
