Broadcast icon

A free broadcast icon from the Communication set, useful for radio, signal, stream, live. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the broadcast icon in your code

React

import { Broadcast } from '@icon-monks/react';

<Broadcast size={24} />

Vue

<script setup>
import { Broadcast } from '@icon-monks/vue';
</script>

<Broadcast :size="24" />

Web component

<icon-monks name="broadcast" size="24"></icon-monks>

Icon font

<i class="im im-broadcast"></i>

Flutter

Icon(IconMonks.broadcast)

SwiftUI

Image(iconMonks: .broadcast)

Compose

Icon(IconMonks.Regular.Broadcast, contentDescription = null)
