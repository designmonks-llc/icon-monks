Funnel Lightning icon

The funnel lightning icon is a free interface icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the funnel lightning icon

It is the funnel icon with a lightning bolt, for quick actions and power, so it keeps the exact outline of the funnel icon. Use it to stand for funnel, fast and power. The regular weight is a single path made of 5 shapes, and the duotone weight adds a 20% tint behind the outline.

When to use the funnel lightning icon

It belongs to the interface set, made for buttons, menus, toolbars and app navigation. People find it by searching for “funnel”, “fast”, “power” and “instant”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the funnel lightning icon

Is the funnel lightning icon free for commercial use?

Yes. The funnel lightning icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the funnel lightning icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the funnel lightning and funnel icons?

The funnel lightning icon is the funnel icon with a lightning bolt, for quick actions and power. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
