Steering Wheel Slash icon

The steering wheel slash icon is a free transport icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the steering wheel slash icon

It is the crossed-out version of the steering wheel icon, for when it is off, blocked or unavailable, so it keeps the exact outline of the steering wheel icon. Use it to stand for steering wheel, off and disabled. The regular weight is a single path made of 3 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the mouse middle click, pizza cutter and pulley icons. Use the same weight for all of them so they read as one set.

When to use the steering wheel slash icon

It belongs to the transport set, made for vehicles, transit and logistics. People find it by searching for “steering wheel”, “off”, “disabled”, “hidden” and “steering”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the steering wheel slash icon

Is the steering wheel slash icon free for commercial use?

Yes. The steering wheel slash icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the steering wheel slash icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the steering wheel slash and steering wheel icons?

The steering wheel slash icon is the crossed-out version of the steering wheel icon, for when it is off, blocked or unavailable. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
