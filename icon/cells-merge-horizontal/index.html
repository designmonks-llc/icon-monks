Cells Merge Horizontal icon

The cells merge horizontal icon is a free editor icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the cells merge horizontal icon

It is a horizontal variant of the cells merge icon, so it keeps the exact outline of the cells merge icon. Use it to stand for merge cells, table and combine. The regular weight is a single path made of 4 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the border all, unite and object group icons, which share the “table” theme. Use the same weight for all of them so they read as one set.

When to use the cells merge horizontal icon

It belongs to the editor set, made for text editing, formatting and writing tools. People find it by searching for “merge cells”, “table”, “combine” and “horizontal”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the cells merge horizontal icon

Is the cells merge horizontal icon free for commercial use?

Yes. The cells merge horizontal icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the cells merge horizontal icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the cells merge horizontal and cells merge icons?

The cells merge horizontal icon is a horizontal variant of the cells merge icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
