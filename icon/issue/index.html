Issue icon

The issue icon is a free development icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

When to use the issue icon

It belongs to the development set, made for code, terminals, version control and developer tools. People find it by searching for “bug report”, “ticket” and “tracker”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the issue icon

Is the issue icon free for commercial use?

Yes. The issue icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the issue icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the issue icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
