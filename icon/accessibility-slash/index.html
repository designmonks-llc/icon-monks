Accessibility Slash icon

A free accessibility slash icon from the People set, useful for accessibility, a11y, disabled. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the accessibility slash icon in your code

React

import { AccessibilitySlash } from '@icon-monks/react';

<AccessibilitySlash size={24} />

Vue

<script setup>
import { AccessibilitySlash } from '@icon-monks/vue';
</script>

<AccessibilitySlash :size="24" />

Web component

<icon-monks name="accessibility-slash" size="24"></icon-monks>

Icon font

<i class="im im-accessibility-slash"></i>

Flutter

Icon(IconMonks.accessibilitySlash)

SwiftUI

Image(iconMonks: .accessibilitySlash)

Compose

Icon(IconMonks.Regular.AccessibilitySlash, contentDescription = null)
