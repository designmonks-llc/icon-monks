Browser X icon

The browser x icon is a free interface icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the browser x icon

It is the browser icon with an x badge, for cancelling, closing or deleting, so it keeps the exact outline of the browser icon. Use it to stand for close window, page error and close tab. The regular weight is a single path made of 5 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the text indent and macro icons. Use the same weight for all of them so they read as one set.

When to use the browser x icon

It belongs to the interface set, made for buttons, menus, toolbars and app navigation. People find it by searching for “close window”, “page error”, “close tab”, “browser” and “remove”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the browser x icon

Is the browser x icon free for commercial use?

Yes. The browser x icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the browser x icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the browser x and browser icons?

The browser x icon is the browser icon with an x badge, for cancelling, closing or deleting. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
