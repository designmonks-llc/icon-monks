Cloud Fog icon

A free cloud fog icon from the Weather set, useful for fog, mist, haze, weather. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the cloud fog icon in your code

React

import { CloudFog } from '@icon-monks/react';

<CloudFog size={24} />

Vue

<script setup>
import { CloudFog } from '@icon-monks/vue';
</script>

<CloudFog :size="24" />

Web component

<icon-monks name="cloud-fog" size="24"></icon-monks>

Icon font

Flutter

SwiftUI

Image(iconMonks: .cloudFog)

Compose
