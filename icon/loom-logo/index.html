Loom Logo icon

A free loom logo icon from the Brands set, useful for loom, video, screen recording, async video. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the loom logo icon in your code

React

import { LoomLogo } from '@icon-monks/react';

<LoomLogo size={24} />

Vue

<script setup>
import { LoomLogo } from '@icon-monks/vue';
</script>

<LoomLogo :size="24" />

Web component

<icon-monks name="loom-logo" size="24"></icon-monks>

Icon font

<i class="im im-loom-logo"></i>

Flutter

Icon(IconMonks.loomLogo)

SwiftUI

Image(iconMonks: .loomLogo)

Compose

Icon(IconMonks.Regular.LoomLogo, contentDescription = null)
