Notebook icon

A free notebook icon from the Files set, useful for journal, diary, notes, notepad. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the notebook icon in your code

React

import { Notebook } from '@icon-monks/react';

<Notebook size={24} />

Vue

<script setup>
import { Notebook } from '@icon-monks/vue';
</script>

<Notebook :size="24" />

Web component

<icon-monks name="notebook" size="24"></icon-monks>

Icon font

<i class="im im-notebook"></i>

Flutter

Icon(IconMonks.notebook)

SwiftUI

Image(iconMonks: .notebook)

Compose

Icon(IconMonks.Regular.Notebook, contentDescription = null)
