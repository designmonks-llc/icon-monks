Rss Check icon

A free rss check icon from the Communication set, useful for rss, connected, subscribed, feed. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the rss check icon in your code

React

import { RssCheck } from '@icon-monks/react';

<RssCheck size={24} />

Vue

<script setup>
import { RssCheck } from '@icon-monks/vue';
</script>

<RssCheck :size="24" />

Web component

<icon-monks name="rss-check" size="24"></icon-monks>

Icon font

<i class="im im-rss-check"></i>

Flutter

Icon(IconMonks.rssCheck)

SwiftUI

Compose
