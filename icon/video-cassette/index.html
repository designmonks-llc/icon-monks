Video Cassette icon

A free video cassette icon from the Media set, useful for videotape, video cassette, vhs, retro. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the video cassette icon in your code

React

import { VideoCassette } from '@icon-monks/react';

<VideoCassette size={24} />

Vue

<script setup>
import { VideoCassette } from '@icon-monks/vue';
</script>

<VideoCassette :size="24" />

Web component

<icon-monks name="video-cassette" size="24"></icon-monks>

Icon font

<i class="im im-video-cassette"></i>

Flutter

Icon(IconMonks.videoCassette)

SwiftUI

Image(iconMonks: .videoCassette)

Compose

Icon(IconMonks.Regular.VideoCassette, contentDescription = null)
