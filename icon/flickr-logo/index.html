Flickr Logo icon

A free flickr logo icon from the Brands set, useful for flickr, photo sharing, photos, social media. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the flickr logo icon in your code

React

import { FlickrLogo } from '@icon-monks/react';

<FlickrLogo size={24} />

Vue

<script setup>
import { FlickrLogo } from '@icon-monks/vue';
</script>

<FlickrLogo :size="24" />

Web component

<icon-monks name="flickr-logo" size="24"></icon-monks>

Icon font

<i class="im im-flickr-logo"></i>

Flutter

Icon(IconMonks.flickrLogo)

SwiftUI

Image(iconMonks: .flickrLogo)

Compose

Icon(IconMonks.Regular.FlickrLogo, contentDescription = null)
