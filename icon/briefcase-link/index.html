Briefcase Link icon

A free briefcase link icon from the Business set, useful for job link, job posting, career link, job url. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the briefcase link icon in your code

React

import { BriefcaseLink } from '@icon-monks/react';

<BriefcaseLink size={24} />

Vue

<script setup>
import { BriefcaseLink } from '@icon-monks/vue';
</script>

<BriefcaseLink :size="24" />

Web component

<icon-monks name="briefcase-link" size="24"></icon-monks>

Icon font

<i class="im im-briefcase-link"></i>

Flutter

Icon(IconMonks.briefcaseLink)

SwiftUI

Image(iconMonks: .briefcaseLink)

Compose

Icon(IconMonks.Regular.BriefcaseLink, contentDescription = null)
