Briefcase Share icon

A free briefcase share icon from the Business set, useful for share job, refer, job posting, career. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the briefcase share icon in your code

<BriefcaseShare size={24} />

Vue

import { BriefcaseShare } from '@icon-monks/vue';
</script>

Web component

Icon font

SwiftUI
