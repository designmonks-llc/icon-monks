React Logo icon

A free react logo icon from the Brands set, useful for react, reactjs, javascript, framework. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the react logo icon in your code

React

import { ReactLogo } from '@icon-monks/react';

<ReactLogo size={24} />

Vue

<script setup>
import { ReactLogo } from '@icon-monks/vue';
</script>

<ReactLogo :size="24" />

Web component

Icon font

<i class="im im-react-logo"></i>

Flutter

SwiftUI

Image(iconMonks: .reactLogo)

Compose
