Text Wrap icon

A free text wrap icon from the Editor set, useful for text wrap, overflow, word wrap, lines. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text wrap icon in your code

React

import { TextWrap } from '@icon-monks/react';

<TextWrap size={24} />

Vue

<script setup>
import { TextWrap } from '@icon-monks/vue';
</script>

<TextWrap :size="24" />

Web component

<icon-monks name="text-wrap" size="24"></icon-monks>

Icon font

<i class="im im-text-wrap"></i>

Flutter

Icon(IconMonks.textWrap)

SwiftUI

Image(iconMonks: .textWrap)

Compose

Icon(IconMonks.Regular.TextWrap, contentDescription = null)
