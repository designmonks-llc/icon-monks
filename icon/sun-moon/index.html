Sun Moon icon

A free sun moon icon from the Weather set, useful for day night, light dark, theme, cycle. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the sun moon icon in your code

React

import { SunMoon } from '@icon-monks/react';

<SunMoon size={24} />

Vue

<script setup>
import { SunMoon } from '@icon-monks/vue';
</script>

Web component

Icon font

Flutter

SwiftUI

Compose
