User Video icon

A free user video icon from the Communication set, useful for video call, webinar, person, camera. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the user video icon in your code

React

import { UserVideo } from '@icon-monks/react';

<UserVideo size={24} />

Vue

<script setup>
import { UserVideo } from '@icon-monks/vue';
</script>

<UserVideo :size="24" />

Web component

<icon-monks name="user-video" size="24"></icon-monks>

Icon font

<i class="im im-user-video"></i>

Flutter

Icon(IconMonks.userVideo)

SwiftUI

Image(iconMonks: .userVideo)

Compose

Icon(IconMonks.Regular.UserVideo, contentDescription = null)
