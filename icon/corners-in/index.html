Corners In icon

A free corners in icon from the Arrows set, useful for collapse, minimize, exit fullscreen, shrink. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the corners in icon in your code

React

import { CornersIn } from '@icon-monks/react';

<CornersIn size={24} />

Vue

<script setup>
import { CornersIn } from '@icon-monks/vue';
</script>

<CornersIn :size="24" />

Web component

<icon-monks name="corners-in" size="24"></icon-monks>

Icon font

<i class="im im-corners-in"></i>

Flutter

Icon(IconMonks.cornersIn)

SwiftUI

Image(iconMonks: .cornersIn)

Compose

Icon(IconMonks.Regular.CornersIn, contentDescription = null)
