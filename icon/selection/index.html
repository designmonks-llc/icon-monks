Selection icon

A free selection icon from the Interface set, useful for select, marquee, dashed, area. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the selection icon in your code

React

<Selection size={24} />

Vue

<script setup>
import { Selection } from '@icon-monks/vue';
</script>

<Selection :size="24" />

Web component

<icon-monks name="selection" size="24"></icon-monks>

Icon font

<i class="im im-selection"></i>

Flutter

Icon(IconMonks.selection)

SwiftUI

Image(iconMonks: .selection)

Compose

Icon(IconMonks.Regular.Selection, contentDescription = null)
