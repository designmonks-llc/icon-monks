File Dashed icon

A free file dashed icon from the Files set, useful for draft file, placeholder, new file, focus. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the file dashed icon in your code

React

import { FileDashed } from '@icon-monks/react';

<FileDashed size={24} />

Vue

<script setup>
import { FileDashed } from '@icon-monks/vue';
</script>

<FileDashed :size="24" />

Web component

<icon-monks name="file-dashed" size="24"></icon-monks>

Icon font

<i class="im im-file-dashed"></i>

Flutter

Icon(IconMonks.fileDashed)

SwiftUI

Image(iconMonks: .fileDashed)

Compose

Icon(IconMonks.Regular.FileDashed, contentDescription = null)
