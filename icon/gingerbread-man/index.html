Gingerbread Man icon

A free gingerbread man icon from the Food set, useful for gingerbread, cookie, christmas. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the gingerbread man icon in your code

React

import { GingerbreadMan } from '@icon-monks/react';

<GingerbreadMan size={24} />

Vue

<script setup>
import { GingerbreadMan } from '@icon-monks/vue';
</script>

<GingerbreadMan :size="24" />

Web component

Icon font

<i class="im im-gingerbread-man"></i>

Flutter

Icon(IconMonks.gingerbreadMan)

SwiftUI

Image(iconMonks: .gingerbreadMan)

Compose

Icon(IconMonks.Regular.GingerbreadMan, contentDescription = null)
