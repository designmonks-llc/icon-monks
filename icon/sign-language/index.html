Sign Language icon

A free sign language icon from the People set, useful for asl, deaf, gesture, hands. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the sign language icon in your code

React

import { SignLanguage } from '@icon-monks/react';

<SignLanguage size={24} />

Vue

<script setup>
import { SignLanguage } from '@icon-monks/vue';
</script>

<SignLanguage :size="24" />

Web component

<icon-monks name="sign-language" size="24"></icon-monks>

Icon font

<i class="im im-sign-language"></i>

Flutter

Icon(IconMonks.signLanguage)

SwiftUI

Image(iconMonks: .signLanguage)

Compose

Icon(IconMonks.Regular.SignLanguage, contentDescription = null)
