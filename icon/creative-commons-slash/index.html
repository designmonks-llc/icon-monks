Creative Commons Slash icon

A free creative commons slash icon from the Symbols set, useful for creative commons, disabled, off, symbols. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the creative commons slash icon in your code

React

import { CreativeCommonsSlash } from '@icon-monks/react';

<CreativeCommonsSlash size={24} />

Vue

<script setup>
import { CreativeCommonsSlash } from '@icon-monks/vue';
</script>

<CreativeCommonsSlash :size="24" />

Web component

<icon-monks name="creative-commons-slash" size="24"></icon-monks>

Icon font

<i class="im im-creative-commons-slash"></i>

Flutter

Icon(IconMonks.creativeCommonsSlash)

SwiftUI

Image(iconMonks: .creativeCommonsSlash)

Compose

Icon(IconMonks.Regular.CreativeCommonsSlash, contentDescription = null)
