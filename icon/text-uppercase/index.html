Text Uppercase icon

A free text uppercase icon from the Editor set, useful for uppercase, caps, case, typography. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text uppercase icon in your code

React

import { TextUppercase } from '@icon-monks/react';

<TextUppercase size={24} />

Vue

<script setup>
import { TextUppercase } from '@icon-monks/vue';
</script>

<TextUppercase :size="24" />

Web component

<icon-monks name="text-uppercase" size="24"></icon-monks>

Icon font

<i class="im im-text-uppercase"></i>

Flutter

Icon(IconMonks.textUppercase)

SwiftUI

Image(iconMonks: .textUppercase)

Compose

Icon(IconMonks.Regular.TextUppercase, contentDescription = null)
