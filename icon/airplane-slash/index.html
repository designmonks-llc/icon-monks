Airplane Slash icon

A free airplane slash icon from the Transport set, useful for no flights, cancelled flight, airplane mode off, airplane mode. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the airplane slash icon in your code

<AirplaneSlash size={24} />

Vue

<script setup>
import { AirplaneSlash } from '@icon-monks/vue';
</script>

<AirplaneSlash :size="24" />

Web component

Icon font

SwiftUI
