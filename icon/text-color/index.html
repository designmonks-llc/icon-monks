Text Color icon

A free text color icon from the Editor set, useful for font color, text color, letter, highlight. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the text color icon in your code

React

import { TextColor } from '@icon-monks/react';

<TextColor size={24} />

Vue

<script setup>
import { TextColor } from '@icon-monks/vue';
</script>

<TextColor :size="24" />

Web component

<icon-monks name="text-color" size="24"></icon-monks>

Icon font

<i class="im im-text-color"></i>

Flutter

Icon(IconMonks.textColor)

SwiftUI

Image(iconMonks: .textColor)

Compose

Icon(IconMonks.Regular.TextColor, contentDescription = null)
