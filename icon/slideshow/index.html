Slideshow icon

A free slideshow icon from the Interface set, useful for slides, gallery, image viewer, presentation. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the slideshow icon in your code

React

import { Slideshow } from '@icon-monks/react';

<Slideshow size={24} />

Vue

<script setup>
import { Slideshow } from '@icon-monks/vue';
</script>

<Slideshow :size="24" />

Web component

<icon-monks name="slideshow" size="24"></icon-monks>

Icon font

<i class="im im-slideshow"></i>

Flutter

Icon(IconMonks.slideshow)

SwiftUI

Image(iconMonks: .slideshow)

Compose

Icon(IconMonks.Regular.Slideshow, contentDescription = null)
