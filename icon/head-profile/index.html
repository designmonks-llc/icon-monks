Head Profile icon

The head profile icon is a free people icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the head profile icon

Use it to stand for head, profile and side view. The regular weight is a single path made of 1 shape, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the user, man and person arms spread icons, which share the “profile” theme. Use the same weight for all of them so they read as one set.

When to use the head profile icon

It belongs to the people set, made for users, avatars, teams and accessibility. People find it by searching for “head”, “profile”, “side view” and “person”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the head profile icon

Is the head profile icon free for commercial use?

Yes. The head profile icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the head profile icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the head profile icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
