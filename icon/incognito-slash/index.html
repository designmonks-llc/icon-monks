Incognito Slash icon

A free incognito slash icon from the Security set, useful for incognito, off, disabled, hidden. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the incognito slash icon in your code

React

import { IncognitoSlash } from '@icon-monks/react';

<IncognitoSlash size={24} />

Vue

<script setup>
import { IncognitoSlash } from '@icon-monks/vue';
</script>

<IncognitoSlash :size="24" />

Web component

<icon-monks name="incognito-slash" size="24"></icon-monks>

Icon font

<i class="im im-incognito-slash"></i>

Flutter

Icon(IconMonks.incognitoSlash)

SwiftUI

Image(iconMonks: .incognitoSlash)

Compose

Icon(IconMonks.Regular.IncognitoSlash, contentDescription = null)
