Postcard icon

A free postcard icon from the Communication set, useful for mail, card, greeting, travel. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the postcard icon in your code

React

import { Postcard } from '@icon-monks/react';

<Postcard size={24} />

Vue

<script setup>
import { Postcard } from '@icon-monks/vue';
</script>

<Postcard :size="24" />

Web component

<icon-monks name="postcard" size="24"></icon-monks>

Icon font

<i class="im im-postcard"></i>

Flutter

Icon(IconMonks.postcard)

SwiftUI

Image(iconMonks: .postcard)

Compose

Icon(IconMonks.Regular.Postcard, contentDescription = null)
