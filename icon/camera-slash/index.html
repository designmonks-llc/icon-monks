Camera Slash icon

A free camera slash icon from the Media set, useful for no photography, camera off, no photos, disabled. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

import { CameraSlash } from '@icon-monks/vue';
</script>

Web component

Icon font

SwiftUI
