Camera Slash icon

The camera slash icon is a free media icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the camera slash icon

It is the crossed-out version of the camera icon, for when it is off, blocked or unavailable, so it keeps the exact outline of the camera icon. Use it to stand for no photography, camera off and no photos. The regular weight is a single path made of 4 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the folder image, grid golden ratio and notebook image icons. Use the same weight for all of them so they read as one set.

When to use the camera slash icon

It belongs to the media set, made for audio, video, playback and streaming controls. People find it by searching for “no photography”, “camera off”, “no photos”, “disabled” and “no camera”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the camera slash icon

Is the camera slash icon free for commercial use?

Yes. The camera slash icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the camera slash icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the camera slash and camera icons?

The camera slash icon is the crossed-out version of the camera icon, for when it is off, blocked or unavailable. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
