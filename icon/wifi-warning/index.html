Wifi Warning icon

A free wifi warning icon from the Devices set, useful for weak connection, network problem, wifi alert, connection problem. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the wifi warning icon in your code

React

import { WifiWarning } from '@icon-monks/react';

<WifiWarning size={24} />

Vue

<script setup>
import { WifiWarning } from '@icon-monks/vue';
</script>

<WifiWarning :size="24" />

Web component

<icon-monks name="wifi-warning" size="24"></icon-monks>

Icon font

<i class="im im-wifi-warning"></i>

Flutter

Icon(IconMonks.wifiWarning)

SwiftUI

Image(iconMonks: .wifiWarning)

Compose

Icon(IconMonks.Regular.WifiWarning, contentDescription = null)
