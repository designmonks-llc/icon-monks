Sign Out icon

A free sign out icon from the Arrows set, useful for logout, exit, log out, leave. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the sign out icon in your code

React

import { SignOut } from '@icon-monks/react';

<SignOut size={24} />

Vue

<script setup>
import { SignOut } from '@icon-monks/vue';
</script>

<SignOut :size="24" />

Web component

<icon-monks name="sign-out" size="24"></icon-monks>

Icon font

<i class="im im-sign-out"></i>

Flutter

Icon(IconMonks.signOut)

SwiftUI

Image(iconMonks: .signOut)

Compose

Icon(IconMonks.Regular.SignOut, contentDescription = null)
