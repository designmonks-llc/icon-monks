Layout Cards icon

The layout cards icon is a free interface icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the layout cards icon

It is a cards variant of the layout icon, so it keeps the exact outline of the layout icon. Use it to stand for cards, layout and tiles. The regular weight is a single path made of 6 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the grid six, panel left right dashed and panels top left icons, which share the “layout” theme. Use the same weight for all of them so they read as one set.

When to use the layout cards icon

It belongs to the interface set, made for buttons, menus, toolbars and app navigation. People find it by searching for “cards”, “layout”, “tiles” and “panels”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the layout cards icon

Is the layout cards icon free for commercial use?

Yes. The layout cards icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the layout cards icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the layout cards and layout icons?

The layout cards icon is a cards variant of the layout icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
