Album icon

A free album icon from the Media set, useful for record sleeve, music, collection. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the album icon in your code

React

import { Album } from '@icon-monks/react';

<Album size={24} />

Vue

<script setup>
import { Album } from '@icon-monks/vue';
</script>

<Album :size="24" />

Web component

<icon-monks name="album" size="24"></icon-monks>

Icon font

<i class="im im-album"></i>

Flutter

Icon(IconMonks.album)

SwiftUI

Image(iconMonks: .album)

Compose

Icon(IconMonks.Regular.Album, contentDescription = null)
