Tauri Logo icon

The tauri logo icon is a free brands icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the tauri logo icon

Use it to stand for tauri, desktop app and rust. The regular weight is a single path made of 4 shapes.

Pairs well with the file rs and app window icons, which share the “rust” theme. Use the same weight for all of them so they read as one set.

When to use the tauri logo icon

It belongs to the brands set, made for sign-in buttons, footers, share menus and integrations. People find it by searching for “tauri”, “desktop app”, “rust”, “framework”, “logo” and “brand”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the tauri logo icon

Is the tauri logo icon free for commercial use?

Yes. The tauri logo icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the tauri logo icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Which weight of the tauri logo icon should I use?

Use regular at 24 px for most interfaces, bold at 16 px or on busy screens, thin or light for large display sizes, fill for a selected or active state, and duotone for illustrations and empty states.
