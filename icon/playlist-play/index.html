Playlist Play icon

The playlist play icon is a free media icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the playlist play icon

It is a play variant of the playlist icon, so it keeps the exact outline of the playlist icon. Use it to stand for play queue, play list and start playlist. The regular weight is a single path made of 5 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the album, git merge queue and monitor plus icons. Use the same weight for all of them so they read as one set.

When to use the playlist play icon

It belongs to the media set, made for audio, video, playback and streaming controls. People find it by searching for “play queue”, “play list” and “start playlist”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the playlist play icon

Is the playlist play icon free for commercial use?

Yes. The playlist play icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the playlist play icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the playlist play and playlist icons?

The playlist play icon is a play variant of the playlist icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
