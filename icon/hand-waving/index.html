Hand Waving icon

A free hand waving icon from the People set, useful for hello, hi, wave, greeting. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the hand waving icon in your code

React

import { HandWaving } from '@icon-monks/react';

<HandWaving size={24} />

Vue

<script setup>
import { HandWaving } from '@icon-monks/vue';
</script>

<HandWaving :size="24" />

Web component

<icon-monks name="hand-waving" size="24"></icon-monks>

Icon font

<i class="im im-hand-waving"></i>

Flutter

Icon(IconMonks.handWaving)

SwiftUI

Image(iconMonks: .handWaving)

Compose

Icon(IconMonks.Regular.HandWaving, contentDescription = null)
