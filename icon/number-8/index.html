Number 8 icon

The number 8 icon is a free letters & numbers icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the number 8 icon

Use it to stand for eight, 8 and digit. The regular weight is a single path made of 3 shapes. It comes with 2 variants for states and actions: number 8 circle and number 8 square.

Pairs well with the billiard ball, calendar 1 and file digit icons, which share the “digit” theme. Use the same weight for all of them so they read as one set.

When to use the number 8 icon

It belongs to the letters & numbers set, made for labels, badges, counters and alphabets. People find it by searching for “eight”, “8”, “digit”, “number 8” and “numeral”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the number 8 icon

Is the number 8 icon free for commercial use?

Yes. The number 8 icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the number 8 icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

Are there variants of the number 8 icon?

Yes. The number 8 icon has 2 variants, including number 8 circle and number 8 square. Each one keeps the same base shape and comes in all six weights.
