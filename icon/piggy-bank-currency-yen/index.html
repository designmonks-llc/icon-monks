Piggy Bank Currency Yen icon

The piggy bank currency yen icon is a free commerce icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the piggy bank currency yen icon

It is a currency yen variant of the piggy bank icon, so it keeps the exact outline of the piggy bank icon. Use it to stand for save yen, savings and piggy bank. The regular weight is a single path made of 7 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the pig and archive icons. Use the same weight for all of them so they read as one set.

When to use the piggy bank currency yen icon

It belongs to the commerce set, made for shops, carts, payments and checkout flows. People find it by searching for “save yen”, “savings”, “piggy bank”, “deposit”, “jpy” and “currency”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the piggy bank currency yen icon

Is the piggy bank currency yen icon free for commercial use?

Yes. The piggy bank currency yen icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the piggy bank currency yen icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the piggy bank currency yen and piggy bank icons?

The piggy bank currency yen icon is a currency yen variant of the piggy bank icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
