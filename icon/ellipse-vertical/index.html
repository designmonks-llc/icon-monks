Ellipse Vertical icon

The ellipse vertical icon is a free design icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the ellipse vertical icon

It is a vertical variant of the ellipse icon, so it keeps the exact outline of the ellipse icon. Use it to stand for vertical ellipse, oval and shape. The regular weight is a single path made of 2 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the blob, capsule and cone icons, which share the “shape” theme. Use the same weight for all of them so they read as one set.

When to use the ellipse vertical icon

It belongs to the design set, made for design tools, editors and creative apps. People find it by searching for “vertical ellipse”, “oval”, “shape” and “egg”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the ellipse vertical icon

Is the ellipse vertical icon free for commercial use?

Yes. The ellipse vertical icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the ellipse vertical icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the ellipse vertical and ellipse icons?

The ellipse vertical icon is a vertical variant of the ellipse icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
