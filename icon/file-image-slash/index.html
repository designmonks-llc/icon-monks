File Image Slash icon

A free file image slash icon from the Files set, useful for no image, image off, document, slash. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

<FileImageSlash size={24} />

Vue

<script setup>
import { FileImageSlash } from '@icon-monks/vue';
</script>

Web component

SwiftUI
