Sticker icon

A free sticker icon from the Emoji set, useful for emoji, peel, smiley, emoji sticker. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the sticker icon in your code

React

import { Sticker } from '@icon-monks/react';

<Sticker size={24} />

Vue

<script setup>
import { Sticker } from '@icon-monks/vue';
</script>

<Sticker :size="24" />

Web component

<icon-monks name="sticker" size="24"></icon-monks>

Icon font

<i class="im im-sticker"></i>

Flutter

Icon(IconMonks.sticker)

SwiftUI

Image(iconMonks: .sticker)

Compose

Icon(IconMonks.Regular.Sticker, contentDescription = null)
