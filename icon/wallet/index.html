Wallet icon

A free wallet icon from the Commerce set, useful for money, purse, payment, cash. It comes in six weights and is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

Use the wallet icon in your code

React

import { Wallet } from '@icon-monks/react';

<Wallet size={24} />

Vue

<script setup>
import { Wallet } from '@icon-monks/vue';
</script>

<Wallet :size="24" />

Web component

<icon-monks name="wallet" size="24"></icon-monks>

Icon font

<i class="im im-wallet"></i>

Flutter

Icon(IconMonks.wallet)

SwiftUI

Image(iconMonks: .wallet)

Compose

Icon(IconMonks.Regular.Wallet, contentDescription = null)
