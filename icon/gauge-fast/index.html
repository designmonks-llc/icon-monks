Gauge Fast icon

The gauge fast icon is a free time icon from Icon Monks, drawn as one clean path on a 256-unit grid in six weights. It is free for personal and commercial use under the MIT license.

Open in the icon browserCustomize size and color, then download PNG, WebP or PDF.

About the gauge fast icon

It is a fast variant of the gauge icon, so it keeps the exact outline of the gauge icon. Use it to stand for speed up, speed and increase. The regular weight is a single path made of 3 shapes, and the duotone weight adds a 20% tint behind the outline.

Pairs well with the calendar arrow up, clock arrow up and stopwatch icons, which share the “speed” theme. Use the same weight for all of them so they read as one set.

When to use the gauge fast icon

It belongs to the time set, made for clocks, calendars, timers and scheduling. People find it by searching for “speed up”, “speed”, “increase” and “meter”. Pair it with the related icons below so a screen stays in one visual style.

Questions about the gauge fast icon

Is the gauge fast icon free for commercial use?

Yes. The gauge fast icon is released under the MIT license, so you can use it in personal, client and commercial projects without paying or adding credit in your interface.

How do I change the color and size of the gauge fast icon?

The icon draws in currentColor, so it takes the text color around it. In React, Vue and the web component, set the size and color props; in the icon browser, pick a color and size before you download a PNG, WebP, SVG or PDF.

What is the difference between the gauge fast and gauge icons?

The gauge fast icon is a fast variant of the gauge icon. Both share the same outline and come in all six weights, so you can swap one for the other to show a change of state.
