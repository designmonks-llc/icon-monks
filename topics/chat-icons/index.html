Frequently asked questions

Are these chat icons free?

Yes. All 91 chat icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface. Brand logos remain trademarks of their owners, so follow each brand's guidelines.

Can I download the chat icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use chat icons in React or Flutter?

Install the package for your platform and import the icon by name, for example Chat from @icon-monks/react or IconMonks.chat in Flutter. Each icon page has copy-ready code for every platform.
