Frequently asked questions

Are these drop icons free?

Yes. All 34 drop icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface. Brand logos remain trademarks of their owners, so follow each brand's guidelines.

Can I download the drop icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use drop icons in React or Flutter?

Install the package for your platform and import the icon by name, for example Drop from @icon-monks/react or IconMonks.drop in Flutter. Each icon page has copy-ready code for every platform.
