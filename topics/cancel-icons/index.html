Frequently asked questions

Are these cancel icons free?

Yes. All 35 cancel icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface.

Can I download the cancel icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use cancel icons in React or Flutter?

Install the package for your platform and import the icon by name, for example X from @icon-monks/react or IconMonks.x in Flutter. Each icon page has copy-ready code for every platform.
