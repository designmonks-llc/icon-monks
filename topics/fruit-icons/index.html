Frequently asked questions

Are these fruit icons free?

Yes. All 16 fruit icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface.

Can I download the fruit icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use fruit icons in React or Flutter?

Install the package for your platform and import the icon by name, for example Pear from @icon-monks/react or IconMonks.pear in Flutter. Each icon page has copy-ready code for every platform.
