Frequently asked questions

Are these math icons free?

Yes. All 60 math icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface.

Can I download the math icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use math icons in React or Flutter?

Install the package for your platform and import the icon by name, for example Pi from @icon-monks/react or IconMonks.pi in Flutter. Each icon page has copy-ready code for every platform.
