Frequently asked questions

Are these file type icons free?

Yes. All 47 file type icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface.

Can I download the file type icons as SVG and PNG?

Yes. Open any icon to download it as SVG in six weights, or open it in the icon browser to pick a size and color and export PNG, WebP or PDF.

How do I use file type icons in React or Flutter?

Install the package for your platform and import the icon by name, for example FileAi from @icon-monks/react or IconMonks.fileAi in Flutter. Each icon page has copy-ready code for every platform.
