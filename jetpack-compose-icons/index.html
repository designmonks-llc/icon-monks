Jetpack Compose and Android icons

4,732 free icons for Android, as Jetpack Compose ImageVectors and classic XML VectorDrawables.

Install

// settings.gradle.kts
dependencyResolutionManagement { repositories { google(); mavenCentral(); maven("https://jitpack.io") } }

// app/build.gradle.kts
implementation("com.github.designmonks:icon-monks:v0.3.0")

Jetpack Compose

import com.designmonks.icons.IconMonks
import com.designmonks.icons.regular.House
import com.designmonks.icons.bold.Heart

Icon(IconMonks.Regular.House, contentDescription = "Home")
Icon(IconMonks.Bold.Heart, contentDescription = null, tint = Color.Red)

Views and XML

<ImageView android:src="@drawable/im_house" app:tint="@color/brand" />
<ImageView android:src="@drawable/im_heart_fill" />

Drawables use ?android:attr/colorControlNormal as their tint, matching Material icons.

Frequently asked questions

Will all icons be added to my APK?

No. Each Compose icon is a separate extension property, so only the icons you reference are compiled in, and R8 removes unused drawables.

Can I use them with Material 3?

Yes. They are standard ImageVectors, so they work with Icon, IconButton, NavigationBar and any Material 3 component.

Is there a version for Kotlin Multiplatform?

Not yet. The package targets Android; the SVG files work in other Kotlin targets.
