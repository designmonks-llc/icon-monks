SVG icons

5,518 clean, single-path SVG icons in six weights that use currentColor, so they take your text color anywhere.

Download or link a file

Open any icon's page to download it, or link the file directly:

<img src="https://designmonks.github.io/icon-monks/svg/regular/house.svg" alt="Home" width="24" height="24">

Install the package

npm install @icon-monks/core

import { toSvg } from '@icon-monks/core';
document.body.innerHTML = toSvg('house', { weight: 'bold', size: 32, color: '#6d28d9' });

Sprites and metadata

The package also includes one SVG sprite per weight (<use href="sprite/regular.svg#house"/>) and icons.json with names, categories and tags for building your own search.

Frequently asked questions

Are the SVGs optimized?

Yes. Each icon is a single flat path on a 256-unit viewBox with no strokes, so it renders the same everywhere and stays small.

Can I change the color?

Inline SVGs use currentColor and follow your CSS color. For tags, pick a color in the icon browser and download a recolored file.

Can I use them in Figma?

Yes. Download the SVG or copy the markup from the icon browser and paste it onto your canvas.
