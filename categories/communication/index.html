Frequently asked questions

Are these communication icons free?

Yes. All 194 communication icons are free for personal and commercial use under the MIT license, with no sign-up and no credit needed in your interface.

How do I use these communication icons in React, Flutter or iOS?

Install the package for your platform and import an icon by name, for example Rss in React or IconMonks.rss in Flutter. Each icon page has copy-ready code for React, Vue, web components, the icon font, Flutter, SwiftUI and Jetpack Compose.

Can I download all communication icons at once?

Yes. Every icon is in the svg folder of the GitHub repository, and the @icon-monks/core npm package includes all of them plus one SVG sprite per weight.
