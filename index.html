Get started in a minute

  
No account, no API key and no build step required. Pick whichever fits your project.

  

    
Link the icon font
One stylesheet, then a class per icon. Works in any HTML page.


<link rel="stylesheet" href="https://designmonks.github.io/icon-monks/packages/font/dist/index.css">
<i class="im im-house"></i>

    
Drop in an SVG
Every icon and weight is a standalone file you can link, inline or download.


<img src="https://designmonks.github.io/icon-monks/svg/bold/heart.svg"
     alt="" width="24" height="24">

    
Install a package
Typed components with size, color and weight props, imported one icon at a time.


import { House } from '@icon-monks/react';
<House size={24} weight="duotone" />

  






  
Six weights, one consistent family

  
Every icon is drawn once and generated in six weights from the same shapes, so outline, filled and duotone versions always line up when you switch states or themes.

  

    
Thin
8-unit stroke for large, quiet display sizes.

    
Light
12-unit stroke for airy interfaces and marketing pages.

    
Regular
The 16-unit default, tuned for 24 px UI.

    
Bold
24-unit stroke that holds up at 16 px and on busy screens.

    
Fill
Solid shapes for selected states and tab bars.

    
Duotone
An outline over a 20% tint for illustrations and empty states.

  






  
Native packages for every platform

  
Every package is generated from the same SVG sources, so an icon looks identical in a React app, a Flutter screen and an iOS tab bar.

  

    
React
Tree-shakeable components with an IconContext for defaults.
npm i @icon-monks/react

    
Vue 3
Components with provide/inject defaults.
npm i @icon-monks/vue

    
Web Components
A <icon-monks> element for plain HTML, Svelte, Angular or WordPress.
npm i @icon-monks/web

    
Icon font
OTF and WOFF2 with CSS classes, five weights.
npm i @icon-monks/font

    
SVG & sprites
Raw files, sprites, metadata and a toSvg() helper.
npm i @icon-monks/core

    
Flutter
IconData constants backed by bundled fonts.
flutter pub add icon_monks

    
Android
Jetpack Compose ImageVectors and XML VectorDrawables.
com.github.designmonks:icon-monks

    
iOS & macOS
Swift Package with vector assets for SwiftUI and UIKit.
Image(iconMonks: .house)

  






  
Drawn for real interfaces

  
Icon Monks is built by Design Monks, a product design studio, for the screens we design every day.

  

    
A strict 256-unit grid
Shapes sit inside a 192-unit live area with shared keylines, so circles, squares and tall shapes carry the same visual weight.

    
Built for small sizes
Regular reads cleanly at 24 px, bold holds up in 16 px menus, and thin and light suit large display sizes.

    
One clean path per icon
Strokes are outlined into a single flat path, so icons render the same in browsers, fonts, Android Studio and Xcode.

    
Themeable by default
Icons use currentColor, so they follow your text color, dark mode and design tokens without extra CSS.

    
Lightweight and tree-shakeable
Import only the icons you use. Unused icons never reach your bundle, and native packages ship vectors instead of images.

    
Original and open
Every icon is original artwork released under MIT. Use it in client work and paid products with no attribution required.

Frequently asked questions

  

    
Is Icon Monks free for commercial projects?
Yes. Every icon is released under the MIT license, so you can use it in personal, client and commercial work, modify it and ship it in paid products. No credit is needed in your interface; keep the license file if you redistribute the source.

    
How many icons are in Icon Monks?
There are 5,518 icons in 31 categories, and each one comes in six weights, which makes 33,108 ready-to-use SVG files.

    
Which frameworks and platforms does it support?
There are packages for React, Vue 3, Web Components (plain HTML, Angular, Svelte, Astro, WordPress), an icon font, Flutter, Android (Jetpack Compose and VectorDrawable) and Apple platforms through a Swift package for SwiftUI and UIKit. Raw SVG files work everywhere else.

    
What are the six weights?
Thin, light, regular and bold are outlines with 8, 12, 16 and 24 unit strokes on a 256 unit grid. Fill is a solid version and duotone layers the outline over a soft tint. Every weight shares the same shapes, so you can mix them in one product.

    
Can I change the size and color of the icons?
Yes. Icons draw in currentColor and scale as vectors, so they take the text color and size of their surroundings. The React, Vue and web component packages also accept size, color and weight props.

    
Can I use the icons in Figma, Sketch or Illustrator?
Yes. Pick an icon on this page and download it as SVG or PDF, or copy the SVG markup and paste it straight onto your canvas. PNG and WebP exports go up to 1024 px.

    
Will the packages make my app bigger?
Only by the icons you use. The React and Vue packages export each icon as its own module, so bundlers drop the rest, and the native packages ship vector assets rather than images.

    
How do I request or contribute an icon?
Open an issue on GitHub to request one. To contribute, draw a source SVG on the 256 unit grid; the build generates every weight and package from it.
