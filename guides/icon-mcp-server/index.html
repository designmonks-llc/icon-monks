Use Icon Monks from AI coding tools with the MCP server

Icon Monks ships a Model Context Protocol (MCP) server in @icon-monks/core. Add one line to your AI assistant's MCP settings and it can search the whole library by concept, then write the exact SVG or import code for your platform, instead of guessing icon names that do not exist.

Steps

  1. Check you have Node.js. The server runs with npx, which comes with Node.js. It has no other dependencies.
  2. Add the server to your MCP client. Use the command npx -y -p @icon-monks/core icon-monks-mcp. The snippets below show the config for common clients.
  3. Restart or reload the client. Most clients load MCP servers at start-up. After a restart, the icon-monks tools appear in the tool list.
  4. Ask for icons in plain words. For example: "add an upload icon to this button in the bold weight". The assistant searches, picks a name and inserts the code.

Config for Claude, Cursor and other clients

{
  "mcpServers": {
    "icon-monks": {
      "command": "npx",
      "args": ["-y", "-p", "@icon-monks/core", "icon-monks-mcp"]
    }
  }
}

This mcpServers block works in Claude Desktop, Cursor (.cursor/mcp.json) and most other MCP clients. In Claude Code you can add it from the terminal instead:

claude mcp add icon-monks -- npx -y -p @icon-monks/core icon-monks-mcp

VS Code reads .vscode/mcp.json, which names the block servers instead of mcpServers; the command and arguments are the same.

What the server can do

ToolWhat it does
search_iconsFinds icons by name, concept or tag, with an optional category filter
get_icon_svgReturns SVG markup in any of the six weights, at a size from 8 to 1024 px and in any color
get_icon_codeReturns ready-to-paste code for React, Vue, HTML (web component), the icon font, Flutter, SwiftUI, Jetpack Compose or inline SVG
list_categoriesLists the categories and how many icons each has

Why use it instead of asking the model

Language models often invent icon names or mix names from different libraries. The server answers from the real icon list in the installed package, so every name it returns exists and every snippet matches the package's actual API. It runs locally over standard input and output and does not send your code anywhere.

Limits

Duotone is not available in the icon font or the Flutter package, so the server says so and suggests SVG or a component package instead. The server needs Node.js; it is not a hosted service.

Frequently asked questions

Is there an MCP server for icons?

Yes. Icon Monks includes one in the @icon-monks/core npm package. Run it with npx -y -p @icon-monks/core icon-monks-mcp and add it to Claude, Cursor, VS Code or any MCP client.

Is the Icon Monks MCP server free?

Yes. It is part of the MIT-licensed @icon-monks/core package, and the icons it returns are MIT licensed with no attribution needed.

Does the MCP server need an API key or internet access?

No API key. npx downloads the package the first time; after that the server reads icons from the installed package on your machine.
