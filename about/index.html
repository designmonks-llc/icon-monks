About Icon Monks

Icon Monks is a free, open source icon library made by Design Monks, a product design studio founded by Atiqur Rahaman. It has 6,054 icons, each drawn in six weights, with native packages for the web, iOS and Android.

Who makes Icon Monks

Icon Monks is designed and maintained by Design Monks, a product design studio based in Mount Arlington, New Jersey. The studio was founded by Atiqur Rahaman (Founder & CEO, Design Monks & Dev Monks), who leads the project.

Design Monks draws these icons for the websites, web apps and mobile apps it designs, and releases the same set for anyone to use.

How the icons are drawn

Every icon starts as one source drawing on a 256-unit grid. The build turns it into six weights with 8, 12, 16 and 24-unit outline strokes plus fill and duotone, then generates every package from the same files, so an icon looks the same in React, Flutter, SwiftUI and Compose. Each icon is a single clean path with no strokes left in the file, tuned to stay sharp at 16 and 24 px. The rules are written up in the style guide.

Why it is free

Icons are basic building blocks, and a team should not need a subscription or a legal review to use them. The MIT license lets you use, change and ship the icons in commercial work with no credit needed in your interface.

Contact and contributing

Email hello@iconmonks.co for anything about Icon Monks. Request an icon or report a problem in GitHub issues. To contribute, draw a source SVG on the 256-unit grid and open a pull request; the build makes every weight and package from it.
